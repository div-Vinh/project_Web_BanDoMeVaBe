# projcet_Web_BanDoMeVaBe
Website Bán Đồ Mẹ & Bé là nền tảng thương mại điện tử giúp người dùng dễ dàng tìm kiếm, lựa chọn và mua sắm các sản phẩm dành cho mẹ và bé như sữa, tã, quần áo, đồ chơi và phụ kiện. Hệ thống hỗ trợ giỏ hàng, thanh toán, quản lý tài khoản, đánh giá sản phẩm và quản trị nội dung, mang đến trải nghiệm mua sắm tiện lợi và an toàn cho khách hàng.
